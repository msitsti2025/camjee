# 깜지 — 과방위 국정감사 질의·답변

국회 과학기술정보방송통신위원회 국정감사에 대비해, 위원별 예상 질문과 답변자료를
태블릿·휴대폰에서 빠르게 찾아보는 웹앱입니다. 설치 없이 브라우저로 씁니다.

```
index.html    앱 (HTML 한 파일, 코드 + 위원 명단)
data.json     공용 데이터 (질문·답변·담당자) ← 직원들이 함께 고치는 파일
```

---

## ⚠️ 공개 배포 전 반드시 확인

- **GitHub Pages로 올린 사이트는 인터넷 전체에 공개됩니다.** 저장소를 비공개로
  해도 Pages 주소는 공개이며, 비공개 사이트는 GitHub Enterprise Cloud에서만 됩니다.
- `data.json`에는 예상 질의·답변과 **담당 과장 개인 휴대폰 번호**가 들어 있습니다.
  발표 전 내부 자료와 개인정보가 그대로 노출되므로, **실제 국감 자료를 담은 채로
  공개 저장소·공개 Pages에 올리지 마십시오.**
- 권장: 저장소는 **비공개(Private)** 로 두고, 실제 운영은 아래 "부처 내부에서 띄우기"
  방식으로 내부망에서만 접속하게 합니다. GitHub은 파일 보관·이력 관리용으로 씁니다.
- 공개 저장소에 꼭 올려야 한다면, 먼저 연락처를 지우십시오.

  ```bash
  python3 -c "import json;d=json.load(open('data.json',encoding='utf-8'));[x.update(c='') for v in d['members'].values() for x in v];json.dump(d,open('data.json','w',encoding='utf-8'),ensure_ascii=False,indent=2)"
  ```

## 쓰는 법

### 조회 (장·차관)

주소를 열면 바로 보입니다. 왼쪽에서 **의원 선택 → 가운데에서 질문 선택 → 오른쪽에
질문(노란 칸)과 답변**이 나옵니다. 위쪽 검색창으로 전 위원의 질문을 한 번에 찾을 수 있습니다.

- **가− / 가＋** — 질의·답변 글자 크기 (100 ~ 200%, 기본 200%). 고른 값은 그 기기에 기억됩니다.
- **▦ 한 화면 / ▤ 페이지** — 세 칸을 한 화면에 보거나, 한 단계씩 넘겨 봅니다.
  기본값은 태블릿·랩톱이면 한 화면, 휴대폰이면 페이지입니다.

### 편집 (직원)

1. 오른쪽 위 **✎ 편집 모드** → 편집 암호 입력 (기본 `kkamji2026`).
2. 질문을 고르고 제목·키워드·질문·답변·담당자를 채운 뒤 **저장**을 누릅니다.
   이 단계까지는 **내 브라우저에만** 저장됩니다 (헤더에 "내 수정 N명 미반영" 표시).
3. **data.json 내보내기** → 받은 `data.json`을 저장소의 파일과 바꿔 커밋합니다.
4. 커밋이 반영되면 모두가 새로고침할 때 최신본을 보게 됩니다.

> 다른 사람이 먼저 올려 공용본이 바뀌면, 다음 접속 때 노란 띠로
> "공용본 불러오기 / 내 수정본 계속 쓰기"를 물어봅니다. 여러 명이 동시에 고친 뒤
> 각자 올리면 나중 것이 앞의 것을 덮으니, **한 번에 한 사람씩** 올리거나
> 위원별로 담당을 나누십시오.

#### 답변 서식

| 입력 | 결과 |
|---|---|
| `**굵게**` | 굵은 글씨 |
| `==형광펜==` | 노란 형광펜 강조 |
| `# 큰제목` / `## 중간제목` | 제목 |
| `- 항목` | 목록 |
| `> 인용` | 인용문 |
| `---` | 구분선 |

이미지는 입력칸에 **끌어다 놓거나 붙여넣기(Ctrl+V)** 하면 첨부됩니다
(폭 1400px·JPEG로 자동 압축). 브라우저 저장 공간이 약 5MB라 이미지는 수십 장이 한계입니다.

## 부처 내부에서 띄우기 (권장)

인터넷에 노출하지 않고 내부망에서만 씁니다. 파일이 있는 폴더에서:

```bash
python3 -m http.server 8080
```

같은 망의 다른 기기에서 `http://서버IP:8080/` 으로 접속합니다 (`index.html`이 자동으로 열립니다).
(`data.json`을 읽으려면 이렇게 웹서버로 열어야 합니다. 파일을 더블클릭해 열면
공용본을 못 받고 앱에 내장된 기본 자료만 보이며, 헤더에 "공용 파일 없음"으로 표시됩니다.)

## GitHub Pages로 띄우기

저장소 **Settings → Pages → Source: Deploy from a branch → main / (root)** 로 두면
`https://<계정>.github.io/<저장소>/` 로 열립니다.
올리기 전에 위의 "공개 배포 전 반드시 확인"을 먼저 읽으십시오.

## 편집 암호 바꾸기

암호는 **실수로 답변을 고치는 것을 막는 잠금**이지 보안 장치가 아닙니다.
페이지 소스를 볼 수 있는 사람은 우회할 수 있으므로, 자료 보호는 배포 위치(내부망·비공개)로 해야 합니다.

1. 앱을 열고 브라우저 콘솔(F12)에서 `hashPw("새암호")` 실행
2. 나온 값을 `index.html`의 `EDIT_PW_HASH = "..."` 에 붙여넣고 커밋
